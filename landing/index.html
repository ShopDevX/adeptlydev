The gap

What's inside

Everything, keyed off your own claude

🎯

Feature Coverage

Scores how many of Claude Code's 30+ features your plan uses, with the high-value gaps — one click to add each.

🌿

Token Hygiene

Rates the plan on money-saving habits — Plan Mode, cheap-model routing, cache-friendly ordering, /clear — and adds the ones you're missing.

📊

Usage ledger

Every call's real cost + cache-hit, plus a whole-account view parsed from ~/.claude. 100% local.

👥

Crew runner

Runs an approved plan as a role pipeline — Architect → Builder → Medic → Reviewer + Security (parallel) → PR. Dry-run by default.

🤝

Session handoff

Leave a resume note one Claude session hands to the next — the bridge sessions can't make live.

🔄

Live feature refresh

Ask your own self-updating claude CLI what's new and fold it into the catalogue. No backend, no doc-scraping.

🧩

Stack-aware recipes

Detects your stack from manifests so every recommendation, path, and command fits what you actually build with.

✅

Approvals in git

Plans and approval state live as files. Every dev sees the same thing; git is the only sync layer.

🎙️

Voice + images

Dictate in chat (push-to-talk) or paste a screenshot and ask Claude to read it. Command palette + focus mode included.
